## 🔒 Comprehensive Multi-Layer Security Architecture

1. **Hardware Enclave Cryptographic Signing:** Private keys reside inside the smartphone's hardware Secure Enclave (Apple) or StrongBox Keystore (Android). Keys never leave physical silicon.
2. **Monotonic Nonce State Enforcement:** Each transaction consumes a strictly increasing hardware nonce. Nonces cannot be reset, rolled back, or cloned—even if the operating system is rooted.
3. **In-Flight Escrow & Two-Way A-ACK Confirmation:** Funds are protected in temporary escrow. The payer's vault only commits a balance deduction if the recipient terminal emits a cryptographically valid acoustic acknowledgment tone within 2.8 seconds.
4. **Physical Acoustic Time-of-Flight (ToF) Bounding:** Speed-of-sound propagation ($c \approx 343\text{ m/s}$) guarantees that transactions cannot execute from beyond 1.0 meter, eliminating long-distance relay attacks.
5. **Dynamic Doppler Frequency Phase Lock:** Dynamic symbol demodulation tracks approaching commuter walking velocity ($\kappa = 1 \pm v/c$), preventing signal degradation during rapid movement.
6. **Receiver Auto-Disarm Safeguard:** The listening receiver automatically disarms its microphone sampling pipeline within 5 milliseconds of decoding a valid voucher, preventing room-echo double billing.
